# Shahd Love Desktop

Build the complete SHAHD.EXE website as a multi-page interactive futuristic operating system mixed with a romantic video game.

IMPORTANT: This is a MULTI-PAGE INTERACTIVE WEBSITE, NOT A SCROLLING LANDING PAGE.

# 1. HOMEPAGE — FUTURISTIC DESKTOP
The homepage should look like a beautiful futuristic computer desktop containing an entire universe dedicated to Shahd.
### Main desktop environment
- Beautiful animated futuristic wallpaper.
- Our two cartoon characters sitting together in the center.
- The little fluffy pink-dressed dog sleeping beside us.
- Floating application icons surrounding the characters.
- Subtle glowing particles and animated background elements.
- A futuristic taskbar.
- A digital clock.
- A small heartbeat indicator.
- Occasional floating notifications.

The characters should have idle animations:
- Occasionally looking at each other.
- Smiling.
- Holding hands.
- The boyfriend character occasionally looking toward Shahd.
- The dog sleeping, moving its ears, or changing sleeping positions.

### Floating application icons
Each icon should open its corresponding dedicated page.
Applications:
- FLOWER.GARDEN
- SHAHD.OS
- OUR.FUTURE
- DREAMS.EXE
- ARCADE.EXE
- CALCULATOR.EXE
- LOVE.RECEIPT
- BUG.REPORT
- GIRLFRIEND.STATS
- GYM.INVESTIGATION
- SECRET.NET
- FINAL.LETTER

Use beautiful custom icons instead of generic emoji icons.
When hovering over an application, display a small tooltip explaining what it does.
Icons should have subtle floating animations and glowing hover effects.

# 2. CALCULATOR.EXE — THE LOVE CALCULATOR
Create a fully interactive calculator with a futuristic design.
It should initially look like a normal calculator, but has a secret personality.
Examples:
- 1 + 1 -> "YOU + ME = US ❤️"
- 100 × 100 -> "Still not enough to measure my love."
- LOVE ÷ TIME -> "INFINITY."
- How much I love her / huge values -> "ERROR 404: RESULT TOO LARGE."
- 70 -> "70 YEARS? STILL NOT ENOUGH."
Include a working calculator interface alongside these personalized Easter eggs.

# 3. INFINITE HUG BUTTON
Create a dedicated interactive experience with a large glowing button:
[ SEND ME A HUG ❤️ ]
When clicked:
1. Our cartoon characters run toward each other.
2. They hug.
3. The background fills with animated hearts.
4. The screen pulses softly.
5. Message: "Consider this a hug until I can give you a real one."
Add a counter: HUGS SENT: 0 (increments on click).
Milestones:
- 10 hugs: The dog joins the hug.
- 25 hugs: A heart explosion.
- 50 hugs: A special romantic animation.
- 70 hugs: "70 hugs. And I'd still ask for another."
